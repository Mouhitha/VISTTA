# Avatar provenance

`avatars/student1.avif` and `avatars/student3.avif` are AVIF images. `avatars/student2.webp` is a WebP image. The files were renamed to match their formats, and their bytes match the original Git tree.

The repository contains no attribution or license for the avatars. Inspection found no embedded authorship or license metadata. The owner needs to confirm each image's source and permission to redistribute it before public release.
